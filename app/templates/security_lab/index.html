How VaultPay Uses Cryptography: Educational Architecture

1. SHA-256 for Integrity Fingerprinting:

SHA-256 is used as a deterministic integrity fingerprint over structured transaction representations. A single-bit alteration in transaction parameters produces a radically different 64-character hex digest (the avalanche effect).

2. AES-256-GCM (AEAD):

AES-GCM combines Galois counter mode with GMAC authentication tags. It guarantees confidentiality (sensitive data is opaque) and authenticity (any tampering with ciphertext, tag, or AAD triggers an immediate InvalidTag rejection).

3. Important Note on Password Hashing:

In this educational project, salted SHA-256 is implemented for passwords and PINs to demonstrate hashing concepts. However, in production banking applications, memory-hard algorithms such as Argon2id, bcrypt, or scrypt must be used to resist GPU/ASIC brute-force attacks.

"Cryptography does not make a system invulnerable. It provides specific confidentiality, integrity, and authentication properties when implemented and used correctly."
